# المرحلة 19 — التقارير التشغيلية وتقارير التدقيق التفصيلية

تضيف هذه المرحلة محرك تقارير مستقلًا يعتمد على جداول SQLite الموجودة بالفعل، دون ترحيل أو تعديل بنية قاعدة البيانات.

## التقارير الجديدة
- أخطاء الرقم القومي.
- تعارض النوع.
- ملاحظات التجنيد والحالات الحرجة.
- تكرار أرقام الجلوس.
- سجل دفعات الاستيراد.
- سجل نشاط المستخدمين.
- أنماط ملفات Excel التي تعلمها البرنامج.
- تصحيحات ربط الأعمدة التي أكدها الموظفون.
- ملخص حسابات المستخدمين وحالات نشاطها.

## الضوابط
- كل التقارير للقراءة فقط.
- البحث النصي متاح في نتائج التقرير.
- الحد الافتراضي 5000 سجل، مع سقف 20000 لتقليل الضغط على الأجهزة القديمة.
- لا تعرض تقارير المستخدمين كلمات المرور أو التجزئات أو الأملاح السرية.
- لا يتم استنتاج فرقة أو قسم أو حالة دراسية أو نجاح ورسوب من بيانات غير موجودة.
- المحرك مستقل عن واجهة العرض حتى يمكن ربطه بنافذة التقارير وتصدير Excel في خطوة واجهة لاحقة.
