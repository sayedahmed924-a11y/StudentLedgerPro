# المرحلة 20 — منشئ التقارير المخصصة

## ما الجديد
- اختيار الحقول التي ستظهر في التقرير.
- شروط متعددة قابلة للتركيب: يساوي، لا يساوي، يحتوي، لا يحتوي، يبدأ بـ، أكبر/أصغر، بين قيمتين، فارغ/غير فارغ.
- تجميع النتائج حسب أي حقل متاح مع عدد الطلاب والوافدين وغير الوافدين.
- ترتيب وتصنيف النتائج، مع تقسيم الصفحات.
- تصدير Excel وPDF عربي (يتطلب reportlab وarabic-reshaper وpython-bidi وخطاً عربياً مثبتاً).
- لا ينفذ SQL يقدمه المستخدم؛ أسماء الحقول وعوامل المقارنة محصورة في قائمة مسموح بها والقيم تمر كمقارنات آمنة.
- لا يغير قاعدة البيانات أو بيانات الطلاب.

## حدود صريحة
الحقول المتاحة هي فقط ما يخزنه النظام حالياً: الاسم والكود والرقم القومي/المعرف والتصنيف وملف المصدر والتواريخ وعلامات التدقيق. لا يمكن إنشاء تقارير سنة دراسية أو فرقة أو قسم أو درجات أو نجاح ورسوب قبل إضافة هذه البيانات إلى نموذج التخزين واستيرادها صراحة.
- الفحص الافتراضي يقرأ حتى 50,000 سجل؛ يعرض التقرير تنبيهاً إذا وصل إلى الحد.
- الحد الافتراضي للعرض 500 سجل، وبحد أقصى 5,000 لكل صفحة لتقليل الضغط على الأجهزة القديمة.
