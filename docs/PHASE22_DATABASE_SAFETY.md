# المرحلة 22 — حماية قاعدة البيانات والنسخ الاحتياطي والاستعادة

## الوظائف
- فحص SQLite باستخدام integrity_check وعرض حجم الملف ووضع journal وعدد السجلات في الجداول الأساسية.
- إنشاء نسخة احتياطية متسقة باستخدام SQLite Backup API، حتى مع تشغيل WAL.
- فحص النسخة بعد إنشائها ومقارنة أعداد السجلات قبل اعتمادها.
- استعادة نسخة سليمة فقط، بعد التحقق من سلامتها ووجود الجداول الأساسية.
- إنشاء نسخة أمان تلقائية من قاعدة البيانات الحالية قبل أي استعادة.
- الاستعادة لا تستبدل الملف يدوياً ولا تحذف ملفات WAL؛ تتم عبر SQLite Backup API.

## الأمان
- ملفات النسخ لا تستبدل قاعدة البيانات الحية.
- لا تقبل ملفات فارغة أو تالفة أو لا تحتوي الجداول الأساسية.
- لا تتم الاستعادة عند فشل الفحص الأولي.
- احتفظ بنسخ احتياطية في وسيط منفصل عن الجهاز عند الإمكان.

## الاختبار
`python -m unittest discover -s tests -p 'test_database_safety.py'`
