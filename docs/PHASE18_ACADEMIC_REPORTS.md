# المرحلة 18 — التقارير الأكاديمية

- كشف جميع الطلاب.
- كشف الطلاب الوافدين وغير المصنفين كوافدين.
- الطلاب الذين ينقصهم الاسم أو الكود أو الرقم القومي.
- الطلاب الذين لديهم أعلام تدقيق أو ملاحظات محفوظة.
- ملخص عدد الطلاب حسب ملف المصدر.
- بحث بالاسم أو الكود أو الرقم القومي أو ملف المصدر.
- نافذة داخل التطبيق مع عرض النتائج وتصدير Excel.

## حدود البيانات
قاعدة البيانات الحالية لا تحفظ بصورة موحدة الفرقة أو القسم أو الشعبة أو الحالة الدراسية أو الدرجات. لذلك لا تعرض هذه المرحلة تقارير نجاح/رسوب أو توزيع حسب الفرقة/القسم أو تخرج. ستضاف هذه التقارير بعد إضافة حقول موثوقة. التقارير للقراءة فقط ولا تغير السجلات.
